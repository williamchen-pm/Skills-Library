How to use skill files on Claude.ai

No CLI required — everything runs in your browser.

What is a skill file?
A SKILL.md is a plain text file that tells Claude exactly how to behave for a specific task — what questions to ask, how to structure its output, which steps to follow, and what guardrails to apply. Think of it as a pre-built expert prompt you upload once and reuse forever. Claude reads it at the start of a conversation and follows it automatically.
Two types of skills on this page
✓ Works immediately

Upload SKILL.md only. No extra files needed. Claude follows the framework and uses web search + your input to produce the output.

Competitive Analysis, Campaign Plan, Brand Voice, SEO Audit, Content Creation, and more.

⚑ Upload references folder too

Upload SKILL.md + all files from the references/ subfolder. Claude reads them as context during the conversation.

ROI Story, Demo Prep, QBR Prep, Account Research, and others that generate structured output files.

Setup: Claude.ai Project (one-time, 3 minutes)
1
Create a Project in Claude.ai

Go to claude.ai → click Projects in the left sidebar → New Project. Name it something like "PM Skills".

2
Skill files available on request

Click Request Sample on any card below. Each skill is a folder containing a SKILL.md and a references/ subfolder.

3
Upload the files to your Project

In your Project, click Add content → Upload files. For ✓ Works immediately skills, upload just the SKILL.md. For ⚑ Upload references skills, upload the SKILL.md plus every file inside the references/ folder.

4
Start a new chat inside the Project

Open your Project → New chat. Claude automatically reads all uploaded files. Use any of the example prompts on the card to trigger the skill, or describe what you need in your own words.

Tips for best results
One skill per Project works best — it keeps Claude focused. You can create multiple Projects, one per skill you use frequently.

Paste context upfront. Skills like ROI Story and Demo Prep ask clarifying questions — the more deal context you include in your first message, the fewer follow-up questions Claude needs to ask.

FP Intelligence connector: Some skills are designed to query internal CRM data via FP Intelligence. If that connector is available on your account, add it to the Project for the best output. Without it, Claude falls back to web search and your pasted input — still useful, just less personalized.
